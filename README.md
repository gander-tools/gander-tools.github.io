# gander-tools.github.io

Landing page for the [gander-tools](https://github.com/gander-tools) organization, published at <https://gander-tools.github.io/>.

gander-tools hosts open-source tools, libraries and userscripts built by [gander](https://github.com/gander).

## Development

The site is built by GitHub Pages with [Jekyll](https://jekyllrb.com/). Projects are listed, in groups, in `_data/projects.yml`; add an entry there to show a new project on the page. Only public repositories belong on the page.

```sh
bundle install
bundle exec jekyll serve
```
